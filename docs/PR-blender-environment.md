# Extend Blender pixel artwork to scenery and terrain

The dinosaur/building rollout leaves the surrounding island with speckled terrain and thin procedural vegetation. This change adds Blender-authored canopies, fronds, rock faces, the volcano and park decorations, plus quieter ground materials and water ripples that match the new animals. The shared default painters apply them throughout the park and Garden artwork; development comparisons retain the original environment.

The set contains 15 scenery types with 38 deterministic variants and 16 terrain materials with four native 16×16 tiles each. Blender MCP authored and reproduced all 102 new grids with identical hashes. Compressed source scenes and authoring scripts stay outside the shipped build. Generated grids and palettes ship in the existing precached application bundle.

The existing scenery sizes, outline padding, tree placement, terrain IDs, per-cell variation and saved-map rules remain stable. The volcano opening still aligns with smoke/glow, and fountain and lamp effects retain their positions. Targeted browser checks verify every scenery/decor texture, all 64 atlas tiles, opaque terrain, footprint agreement, tree fading around animals and hiding/restoring trees under construction. The comparison page now offers all 57 assets with pose/variation controls.

Validation: 272 regular tests plus the separate performance test passed, the regular production build passed, all 13 existing browser tours passed, and the complete art integration check passed with all 57 comparison assets available. The production PWA created a v21 save and resumed the saved park after an offline restart under the Pages subpath. Scenery/terrain galleries and river/coast/volcano park captures are generated by `npm run art:environment` under ignored `docs/art-review/`. The final isolated renderer comparison used 32 dinosaurs and 150 visitors at 844×390. Both original and full Blender artwork measured 50.1 ms p95 frame intervals and about 1.3 ms p95 entity updates. Startup measured 3,027 ms original and 3,223 ms Blender (6.5% higher in this single run). Locally gzipped production files total 595,187 bytes: 8,276 extra bytes over the dinosaur/building rollout, and 19,730 above the pre-pilot build. These headless software-rendering observations include cache/order effects and do not establish physical Safari performance.

Review at `/scripts/art/review.html` or play `/?quickstart&shape=river&seed=7`. Regeneration instructions are in `assets-source/README.md`. Physical iPhone/iPad Safari review remains pending before integration; this graphics branch has not been deployed.
